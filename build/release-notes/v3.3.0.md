## Download

- **MediaConverter-Setup.exe**: Windows 10 and 11. Installs for your account only, no administrator password needed. Installing over an older version keeps your settings.
- **MediaConverter-portable.zip**: Windows, no install. Extract anywhere and run `MediaConverter.exe`.
- **MediaConverter-mac-apple-silicon.dmg**: Macs with an Apple M-series chip.
- **MediaConverter-mac-intel.dmg**: Macs with an Intel processor.

Not sure which Mac you have? Apple menu → About This Mac: "Chip: Apple M…" is Apple silicon, "Processor: Intel" is Intel.

## Opening it the first time

- **Windows** may show *"Windows protected your PC"*: click **More info → Run anyway**.
- **Mac:** open the `.dmg`, drag Media Converter to Applications and open it. macOS will say it can't check the developer, because the app isn't registered with Apple. Go to **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. On macOS 14 and older you can instead right-click the app and choose **Open**.

## Check your download

Compare the file with `SHA256SUMS.txt` (`Get-FileHash` on Windows, `shasum -a 256` on a Mac), or run `gh attestation verify <file> --repo anglerequip/media-converter`. Every file here was built and self-tested by GitHub Actions from the tagged source; see the `BUILD-INFO` files for every input.
